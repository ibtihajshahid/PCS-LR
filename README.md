# PCS-LR | Secure Tactical Communication Node

Long-range (30KM+) encrypted LoRa-based communication system for tactical IoT deployments.

*Live Demo:* https://ibtihajshahid.github.io/PCS-LR/

### Features
- 433MHz LoRa Mesh (TX -> RLY -> RX)
- AES-256 Encrypted Payload Pipeline
- Real-time Telemetry: RSSI, SNR, Latency, Packet Loss
- Estimated Range: ~35 KM (SF12 / 125kHz / 20dBm)

### Tech Stack
Hardware: ESP32, LoRa SX1278, RF 433MHz
Security: AES-256, PSK, IV Verification
Frontend: HTML5, CSS3, Vanilla JS

### How to Run
Just open index.html in any browser. No server needed.
